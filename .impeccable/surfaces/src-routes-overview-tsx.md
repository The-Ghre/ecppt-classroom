## Direction contract

THESIS: The course is one circuit board, and a penetration test is a signal routed through it. Sessions are components on a single routed bus; pivoting is a via to an inner layer; validation is probing a test point; an unproven path is a thin ratsnest line until it is routed copper. It refuses the hacker-terminal costume (phosphor, Matrix, fake CLI), the generic dark dashboard, and the retired Blueprint Console (no graticule grid, no corner ticks, no mono eyebrow above every heading).

OWN-WORLD: Three inks at page scale, all CODED: navy solder mask (#00112f ground, #0a1a3a component bodies), gold ENIG copper (#e0b45c pads/traces, #c89a45 unpowered copper), white silkscreen (#ffffff designators, outlines). Cyan #79e2ec is the live signal only: powered trace, pulse, active probe. Semantic channels (attacker red #f84b4b, valid green #5ad0a0, caution gold, identity violet #c8adff) live inside teaching content and status LEDs, always with label + shape. IBM Plex Sans display, IBM Plex Mono for silkscreen designators, net names, and instrument digits. Recognizable with content removed by: 45-degree chamfered traces, gold pad rows on chip bodies, round vias with a dark drill hole, mounting holes, silkscreen outlines.

STORY: A student sees the whole course as one board, sees how far their signal has travelled, understands that a test is conditions routed toward an objective, and acts by probing a session (study datasheet) or powering it up (present).

FIRST VIEWPORT (overview): Top band: plain bold headline left ("Route the signal. Prove every hop."), short lede, gold primary pad button "Resume / Start" and a ghost button to the attack chain; right, a compact probe readout of the focused component. Directly below, filling the rest of the viewport, the board: five silkscreened week blocks side by side, each with three components (two IC chips for theory, one test header for the lab), joined by one serpentine bus of chamfered gold traces; the trace is powered cyan up to the student's progress with one travelling pulse. Mounting holes at board corners, board name in silkscreen at the edge. Focusing a component promotes it face-out into the probe readout.

FORM: Signal Board (hacker-con PCB badges and component datasheets), the assigned grounded candidate, round-2 cyber-steered roll. Raised by: ratsnest vs routed copper (pattern envelope); instrument digits that change as visible events (nixie); compact footprint promoted face-out on focus (pulp rack); red spent only on the attacker action under pressure (futurist book); named labelled phases, never colour alone (cyclorama). Study mode reads as a component datasheet; the presenter's progress is a trace with one via per slide. Seed key 58f0c4e3, re-roll round 2, kind assigned.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
